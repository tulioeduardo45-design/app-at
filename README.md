# App do AT

Aplicativo de registro de sessões de intervenção (tentativas, dicas, comportamentos, reforçadores e evolução diária) para uso no celular.

- Funciona offline depois do primeiro acesso.
- **Este repositório contém apenas o código do aplicativo. Nenhum dado de paciente é armazenado aqui.**
- Os registros ficam somente no celular de quem usa e são enviados ao supervisor por arquivo.
